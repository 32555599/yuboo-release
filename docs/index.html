它不催你，也不评价你。
它只是把「想」和「做」之间的那段距离，切成你能跨过去的小块。

做完一步得积分，积分换等级，等级解锁称号，一路还有 326 枚奖牌等着。 所有这些都跑在你自己的手机里——不联网、不注册、不上传、不统计。

它是怎么运作的

不用学一套方法论，也不用打卡给别人看。你只要说出想做什么，剩下的它来切。

AI 帮你拆解

内置提示词，复制丢给任意 AI（DeepSeek / 豆包 / Kimi / 通义 / ChatGPT…），把返回的 JSON 粘回来，自动生成带难度和耗时的步骤。

每天只走一步

每一步都有难度、耗时、重要性。今天状态好就挑难一点的，累了就做轻的。可以勾选，也可以跳过。

326 枚奖牌

23 个判定维度：完成数、连续天数、步数、类型广度、时段、单日峰值、完美完成、连击……每一枚都有独立图标。

数据不出手机

没有账号、没有云同步、没有埋点。所有计划与记录存在本地，支持导出备份和导入恢复，也可以一键清空。

长成你喜欢的样子

深色与浅色主题，9 种背景预设，多套强调色。看着舒服，才愿意每天打开。

桌面小部件

四种样式：快速许愿、今日一步、状态、倒计时。不用点开应用，也能看见今天该做什么。
