## 这是什么

大部分待办应用让你自己列清单，但真正难的是**第一步到底做什么**。

鱼步步换了个思路：你只写一句模糊的愿望 —— "想学会吉他弹唱"、"想把房间收拾干净" —— AI 会帮你拆成 10~30 个具体到能立刻上手的步骤。然后你每天只做一步。做完打分、累计积分、解锁成就。

它不想做又一个功能堆砌的管理工具，只想解决一件事：**让"开始"这个动作变得足够轻。**

## 功能

- **AI 拆解** —— 一句话愿望 → 10~30 个可执行步骤，可手改、可增删
- **每天一步** —— 不逼你一次做完，把"坚持"变成一件不需要意志力的事
- **326 枚成就奖牌** —— 计划、连续打卡、积分等级、早起、深夜、周末等 23 个维度，每一枚都有专属图标和一句评语
- **数据只在你手机里** —— 全程离线，不申请联网权限，不上传任何内容，可随时导出备份
- **主题与小部件** —— 多套配色、桌面小组件直接看今日一步
